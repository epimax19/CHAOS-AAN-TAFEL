# CHAOS AAN TAFEL

Een Nederlandstalige partygame voor 2–12 spelers. De game combineert Truth or Dare, Wie van ons?, uitbeelden, opdrachten, bluffen en quizvragen.

## Functies

- Ondersteuning voor 2 tot en met 12 spelers
- Verschillende spelcategorieën en kaarten
- Rad van Chaos: kiest willekeurig een categorie
- Geluidseffecten met aan/uit-bediening
- Speciale kaarten, waaronder dubbele punten, iedereen tegen één speler en geheime opdrachten
- Scoreverwerking en spelverloop
- Responsive vormgeving voor telefoon en laptop

## Lokaal openen

1. Download of kloon deze repository.
2. Open `index.html` in een moderne browser, bijvoorbeeld Google Chrome.
3. Voeg 2–12 spelers toe en start het spel.

Er zijn geen buildstappen of externe packages nodig: dit is een zelfstandige HTML-game.

## Publiceren via GitHub Pages

1. Maak op GitHub een nieuwe repository aan.
2. Upload `index.html` en `README.md` (of upload de volledige projectmap).
3. Open in de repository **Settings → Pages**.
4. Kies bij **Build and deployment** voor **Deploy from a branch**.
5. Selecteer de branch `main` en map `/ (root)` en sla op.
6. Wacht tot GitHub Pages de website publiceert. De website-URL verschijnt op de Pages-instellingenpagina.

Je kunt deze repository ook importeren of koppelen aan Vercel om de game daar als statische website te publiceren.
